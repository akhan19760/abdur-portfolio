# Content assets

The owner's own pictures for the portfolio: project screenshots and anything else
`workflow/content.md` points at. This folder is kept by every purge, like
`content.md`, and every version reads it as content. It is empty for now; see
"Pictures" in `content.md` for what versions use until pictures arrive.

## Naming

`<project-slug>-<what-it-shows>.webp`, in lowercase with hyphens. The project slug is
the project's name in `content.md`, for example:

- `accuratespend-validation-workspace.webp`
- `kunarchgpt-query-dashboard.webp`
- `protocoling-suite-live-transcript.webp`

## Size and format

WebP, under 400 KB each. Crop to what the picture is meant to show, and leave out
anything private: client data, names, emails or credentials.

## Credits and captions

If a picture needs a caption or a credit, add a line under its project in
`content.md`, naming the file.
