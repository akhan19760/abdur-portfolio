# Content assets

The owner's own material for the portfolio: project screenshots and anything else
`workflow/content.md` points at. Kept by every purge, like `content.md`, and read by
every version as content.

Name each file after the project it shows, as a slug, for example
`sceai-platform.png`, `accuratespend-dashboard.png` or `kunarchgpt-1.png`. PNG, JPEG,
WebP or video. Add a line under the project in `content.md` if a picture needs a
caption or a credit.
